#Network Traffic Analysis - Wireshark#
This repository contains network traffic analysis of various malware samples and cyber incidents. Each analysis includes the original PCAP file , detailed investigation methodology, and a formal incident report.

##Future Updates##
This repository will be updated with new samples and analysis as they become available.

These samples are shared for educational purposes only. The PCAP files may contain actual malware traffic. Handle with appropriate caution in isolated environments.
